What is the Synergy Systems API?

A REST API that answers scientific questions with evidence. Every response includes the reasoning behind it — so your application can show why, not just what.

Discovery

Search foods, compounds, mechanisms, biomarkers and conditions in one query.

Explanations

Every answer includes a human-readable biological explanation.

Evidence synthesis

Aggregated evidence with consensus, limitations and gaps.

Recommendations

Evidence-gated suggestions with full rationale.

Product enrichment

Send a product name — receive its nutritional and scientific profile.

Provenance

Every claim carries its source, version and verification status.

Public endpoints

GET /v1/discovery/search

Search across foods, compounds, mechanisms, biomarkers and conditions.

GET /v1/explain/{domain}/{iri}

Get a human-readable scientific explanation for any entity.

GET /v1/synthesize/{domain}/{iri}

Aggregated evidence with consensus, limitations and gaps.

GET /v1/recommend/{domain}/{iri}

Evidence-gated recommendation with full rationale.

POST /v1/products/enrich

Send a product title — receive its nutritional and scientific profile.

GET /v1/foods/{id}/model

Full Digital Food Model for a food.

Code examples

cURL
curl -X GET \
  "https://api.synergysystems.ai/v1/discovery/search?q=nrf2" \
  -H "Authorization: Bearer YOUR_KEY"
Python
from synergy import SynergyClient

client = SynergyClient(api_key="YOUR_KEY")

result = client.discovery.search("spinach")
print(result["items"][0]["name"])
JavaScript
import { SynergyClient } from "synergy-systems";

const client = new SynergyClient({ apiKey: "YOUR_KEY" });

const res = await client.products.enrich(
  "Fresh fruit salad"
);
console.log(res.data.status);

06

FAQ

Is the API free?

Yes. The Free plan is available for students, researchers, prototypes and personal projects — no credit card required.

Is the scientific knowledge verified?

Yes. Evidence passes through verification gates, and DOIs are audited. Unsupported claims are never returned as established.

Can I use the API in a commercial app?

Yes — the Professional plan (coming soon) is designed for commercial applications with volume and SLA needs.

Does every response include an explanation?

Yes. Every scientific answer includes its reasoning chain, evidence and confidence — no black boxes.

What is the uptime guarantee?

The Free plan is best-effort. Professional and Enterprise plans will include SLAs.
